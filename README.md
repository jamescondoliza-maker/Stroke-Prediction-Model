1. Project Overview

This project focuses on developing a Machine Learning model to predict the likelihood of a patient experiencing a stroke based on their health information and medical risk factors.

The system uses Artificial Intelligence (AI) and data analysis techniques to identify patterns in patient data and predict potential stroke risk.

2. Project Objectives

To develop a machine learning model for stroke prediction.

To analyze patient health data and identify stroke risk factors.

To apply AI techniques in healthcare.

To evaluate the performance of the prediction model.

To demonstrate how machine learning can support healthcare decision-making.

3. Technologies Used

Python

Google Colab

Pandas

NumPy

Matplotlib

Seaborn

Scikit-learn

Machine Learning

4. Dataset

The project uses a healthcare stroke prediction dataset containing patient information such as:

Age

Gender

Hypertension

Heart disease

Average glucose level

Body Mass Index (BMI)

Smoking status

Work type

Residence type

Stroke history (target variable)

5. Methodology

The project follows these steps:

Data collection and loading.

Data cleaning and preprocessing.

Exploratory Data Analysis (EDA).

Feature selection and preparation.

Splitting the dataset into training and testing sets.

Training the machine learning model.

Making stroke predictions.

Evaluating model performance using accuracy, precision, recall, F1-score and confusion matrix.

6. Machine Learning Algorithms

The project may use algorithms such as:

Other suitable classification algorithms.
